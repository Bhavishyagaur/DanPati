**Expense Tracker**
A modern, high-performance web application designed to help users track their spending habits and manage budgets with ease. 
Built with React 18 and styled using the latest Tailwind CSS v4 for a lightning-fast development experience and UI.

**🚀 Features**

**Real-time Tracking:** Add and categorize expenses on the fly.

**Visual Analytics:** Data visualization using recharts to provide insights into spending patterns.

**Modern UI/UX:** A clean, responsive interface built with Lucide React icons and Tailwind CSS v4.

**Smooth Animations:** Enhanced user interaction feedback via tw-animate-css.

**Optimized Build:** Powered by Vite for near-instant Hot Module Replacement (HMR) and optimized production bundles.

Installation & Setup
1) **Clone the repository:**
     git clone https://github.com/your-username/expense-tracker.git
     cd expense-tracker

2)   **Install dependencies:**
     npm install
     
3)   **Run the development server:**
     npm run dev

 4) ** Build for production:**
      npm run build


**📂 Project Structure**
Plaintext
├── index.html          # Entry HTML file
├── package.json        # Project metadata and dependencies
├── vite.config.js      # Vite configuration (React & Tailwind plugins)
├── postcss.config.mjs  # PostCSS configuration
└── src/                # Source code (Components, Hooks, Styles)



🔧 Configuration
The project utilizes the new @tailwindcss/vite plugin, which simplifies the build pipeline by handling CSS processing directly within Vite. 
Custom PostCSS plugins can be added in postcss.config.mjs if needed.
